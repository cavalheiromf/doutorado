# Biopython: freely available Python tools for computational molecular biology and bioinformatics

**Authors:** Peter J. A. Cock, Tiago Antao, Jeffrey T. Chang, Brad A. Chapman, Cymon J. Cox, Andrew Dalke, Iddo Friedberg, Thomas Hamelryck, Frank Kauff, Bartek Wilczynski, Michiel J. L. de Hoon  
**Year:** 2009  
**Journal:** *Bioinformatics*, 25(11), 1422–1423  
**DOI:** 10.1093/bioinformatics/btp163  

## Abstract

The Biopython project is an international collaboration of developers of freely available Python tools for computational molecular biology. The Biopython package contains modules for parsing bioinformatics files into Python-usable data structures, providing interfaces to common bioinformatics programs, and performing sequence operations such as translation, alignment, and motif finding. Among these tools, pairwise sequence alignment functionality (`Bio.Align` and `PairwiseAligner`) enables robust global and local sequence alignment of proteins and nucleotides using standard substitution matrices like BLOSUM62 and configurable gap penalties. Biopython is distributed under the Biopython License and is freely available from http://www.biopython.org.
